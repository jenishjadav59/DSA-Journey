\# DSA Journey



My journey of learning Data Structures and Algorithms (DSA) using Java.



\## Goals

\- Learn DSA from fundamentals to advanced topics.

\- Improve problem-solving skills.

\- Prepare for technical interviews.

\- Track my learning progress consistently.



\## Repository Structure

\- `problems/` — Problem solutions organized by platform.

\- `topics/` — Index of problems by data structure and subject.

\- `patterns/` — Index of problems by problem-solving pattern.

\- `algorithms/` — Algorithm notes and implementations.

\- `notes/` — Theory and revision notes.



\## Tracking

\- `Problem-Tracker.csv` — Master record of problems.

\- `Progress.md` — Daily learning log.



\## Guidelines

\- Store each problem solution only once.

\- Record all applicable topics and patterns.

\- Analyze time and space complexity.

\- Revise difficult problems regularly.
